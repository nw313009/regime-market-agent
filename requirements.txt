# THE DATABRICKS APP'S dependencies (Streamlit), installed automatically at deploy time.
#
# IT IS AT THE REPOSITORY ROOT BECAUSE THE APP'S SOURCE ROOT IS THE REPOSITORY ROOT. A Databricks
# App reads app.yaml and requirements.txt from the root of whatever source path it is pointed at,
# and this app imports src/ and reads config/config.yaml — so pointing it at app/ would deploy a
# tree missing both. The root is therefore the only workable source path, and these two files
# followed it here. What used to be at this path is now requirements-dev.txt.
#
#   local venv     -> requirements-dev.txt
#   cluster        -> requirements-databricks.txt
#   Databricks App -> requirements.txt              (this file) + app.yaml
#
# Scope: only what the three pages need to render. The app has no SparkSession and does no model
# fitting, so statsmodels, numpy and exchange_calendars are deliberately absent — it reads Gold
# numbers the pipeline already computed. DO NOT ADD THEM BACK to make an import work: an import
# that needs them in the app is an import the app should not be making.
#
# Never pip-upgrade pandas, numpy or pyarrow on a Databricks CLUSTER either; the runtime pins
# those three against its own Spark build.
