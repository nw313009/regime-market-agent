# LOCAL DEVELOPMENT ENVIRONMENT ONLY — Python 3.12 venv (spec B0).
#
# Fully pinned so local runs are reproducible: pytest against the pure-pandas modeling layer,
# plus editor and type support. Versions are the current releases as of 2026-08-09.
#
# statsmodels must stay at 0.14.6 or later: earlier versions fail to import under pandas 3.
#
# DO NOT install this file on a Databricks cluster. It pins pandas and numpy exactly, and
# NEVER pip-upgrade pandas, numpy or pyarrow on a cluster — the runtime pins those three
# against its own Spark build, and replacing them breaks Spark in ways that surface far from
# the change. For notebooks and job environments use requirements-databricks.txt, which lists
# only the four packages the runtime actually lacks.
#
# The Streamlit app does not read this file either. It reads the ROOT requirements.txt, which is
# the app's file — the two were swapped when the app's source root became the repository root
# (a Databricks App reads app.yaml and requirements.txt from the root of its source path, and the
# app needs src/ and config/ deployed alongside it, so the root is the only workable source).
#
#   local venv     -> requirements-dev.txt          (this file)
#   cluster        -> requirements-databricks.txt
#   Databricks App -> requirements.txt + app.yaml, both at the repository root
